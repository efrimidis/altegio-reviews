# altegio-reviews

Небольшой Node.js-сервис для автоматизации студий TELO. Он получает данные из
Altegio, отдаёт отзывы для сайта, публикует свободные окна в Telegram-канале и
отправляет ежедневный расчёт выплат в закрытую Telegram-группу.

## Возможности

- `GET /altegio-reviews` — последние непустые отзывы с кешем в памяти.
- В 15:00 публикуются оставшиеся окна на сегодня, в 20:00 — окна на завтра.
- Скидка составляет 10%, а при четырёх окнах или меньше — 15%.
- Старый пост с окнами удаляется только после успешной отправки нового.
- В 22:00 отправляется отчёт по состоявшимся визитам и 30% выплате мастерам.
- Telegram-кнопки позволяют отметить уже выполненные выплаты.
- Все расписания и даты используют часовой пояс `Asia/Tashkent`.

Расписание, студии, услуга, цены и шаблоны сообщений находятся в `config.js`.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
cp .env.example .env
npm start
```

Сервис завершит запуск, если не заданы обязательные переменные Altegio:

- `ALTEGIO_BEARER_TOKEN` — партнёрский токен;
- `ALTEGIO_USER_TOKEN` — пользовательский токен;
- `ALTEGIO_COMPANY_ID` — филиал, отзывы которого отдаёт HTTP API.

Настройки Telegram-канала:

- `TELEGRAM_BOT_TOKEN`;
- `TELEGRAM_CHANNEL_ID`.

Настройки закрытой группы с отчётами:

- `REPORT_CHAT_ID`;
- `REPORT_BOT_TOKEN` — необязателен, по умолчанию используется основной бот.

Если Telegram-пара не заполнена полностью, соответствующий планировщик будет
отключён, но HTTP-сервис продолжит работать.

## Ручные публикации

Для ручных маршрутов обязательно задайте `PUBLISH_SECRET`. Если его нет, они
отвечают `503` и ничего не публикуют. Рекомендуемый способ создать секрет:

```bash
openssl rand -hex 32
```

Предпросмотр окон:

```bash
curl -X POST http://localhost:3000/publish-slots \
  -H "Authorization: Bearer $PUBLISH_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"day":"tomorrow","dry":true}'
```

Публикация окон выполняется тем же запросом без `dry`. Допустимые значения
`day`: `today` и `tomorrow`.

Предпросмотр отчёта:

```bash
curl -X POST http://localhost:3000/publish-report \
  -H "Authorization: Bearer $PUBLISH_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"dry":true}'
```

Повторный вызов отчёта в тот же день не создаёт дубликат. Для намеренной
повторной отправки передайте `{"force":true}`.

## Telegram webhook

Чтобы кнопки выплат работали, задайте:

- `RENDER_EXTERNAL_URL` или `PUBLIC_URL` — публичный HTTPS URL сервиса;
- `REPORT_WEBHOOK_SECRET` — отдельная случайная строка из латинских букв, цифр,
  `_` и `-` длиной от 24 до 256 символов.

При старте сервис регистрирует адрес
`/telegram/report-callback` через Telegram Bot API. Без URL или корректного
секрета webhook и кнопки отключаются, а отчёт отправляется без клавиатуры.

## HTTP API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/` | Состояние сервиса и планировщиков |
| `GET` | `/altegio-reviews` | Кешированные отзывы |
| `POST` | `/publish-slots` | Предпросмотр или публикация окон |
| `POST` | `/publish-report` | Предпросмотр или публикация отчёта |
| `POST` | `/telegram/report-callback` | Защищённый Telegram webhook |

## Проверка

```bash
npm test
npm run check
```

`npm run check` проверяет синтаксис всех модулей и запускает тесты фильтрации
окон, порогов скидки, расчёта выплат, пагинации и проверки секретов.

## Состояние и ограничения

ID текущего поста и дата последнего отчёта сохраняются атомарно в `state.json`.
Файл исключён из Git и рассчитан на один экземпляр приложения. При нескольких
репликах или при необходимости сохранять состояние между заменами контейнера
следует перенести эти данные в Redis или другую общую БД.

Кеш отзывов находится только в памяти процесса. Запросы Altegio ограничиваются
по частоте и повторяются при сетевых сбоях, HTTP 429 и временных ошибках 5xx.
